- `@aparajita/capacitor-secure-storage`：iOS Keychain / Android Keystore 存储刷新令牌。

安全存储仅在 `Capacitor.isNativePlatform()` 为真时调用。该插件的网页实现使用 localStorage，
不能用作浏览器里的安全刷新令牌存储。原生前缀按地区隔离，关闭 iCloud 同步，iOS 使用
`KeychainAccess.whenUnlockedThisDeviceOnly`；删除令牌使用自身键，不清除其他插件的数据。
Android 禁止备份，防止加密存储恢复到不同密钥后产生失效会话。

本轮不新增联系人、位置、相机或麦克风权限。不要把服务器密钥、后台凭据或商店私钥写入安装包。
